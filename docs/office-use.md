# 办公室 WebUI 使用说明

使用管理员提供的资料库地址打开浏览器。本机、服务器电脑名、局域网 IP 都可以使用；从同一页面上的按钮提交上传、更新、完善信息与反馈。不要混用两个地址拼接请求。

素材中心上传和更新原件仅支持 **PDF / PNG / JPG / JPEG**，单文件不超过 200MB。项目中心可保存 Word/Excel 等项目原件，在项目详情选择“提取内容”后异步整理 PDF/DOCX/XLSX 内容，再用“搜索项目文件”查询页码、章节或 Sheet/行；部分内容未识别或失败时可重新整理。历史文件仅供参考，不代表公司当前有效资质，也不会变成公司素材。

上传时选择类别、填写标题和经办人。识别完成后打开资料页核对信息；识别结果是待完善候选。更新原件保留历史文件，原有核验需要重新对照新原件确认。

上传失败会显示原因。OCR/事务失败后系统会自动尝试恢复索引和 watch；恢复成功后可继续操作。若错误发生在提交之后，资料可能已保存，先查看资料记录，避免重复入库。批次/再抽取的重试必须沿用原计划或操作 ID，由工具读取原回执。

短时间显示“写入维护中”时请稍候。若持续显示，应由维护者检查 manager 事件中的 `recovery_required` / `manager.recovery_failed`，处理数据库、证据文件、磁盘或索引运行时故障，再通过受控 index/watch start 恢复。不要直接手工删除 maintenance 文件来跳过检查。

提交出现 403 时，从管理员提供的地址重新打开资料库页面再操作。同源保护防止其他网页跨站写入，不提供账号权限控制。反馈入口用于描述问题和附截图；反馈不写入正式资料库。

v0.6 交付独立于现场部署；实际升级须由维护者安排备份和明确的 schema 迁移，再验证 WebUI/manager 与文档功能。开发分支不会自动迁移或部署现场系统。
